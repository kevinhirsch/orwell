Compact & icon buttons — .ow-btn-icon / .ow-btn-compact (#1638)

Compact desktop-chrome primitives for the sub-44px chrome the pill can't serve (gadget-rail / composer / hamburger / model-picker). .ow-btn-icon is a SQUARE, flat icon button (~30px on a fine pointer, subtle radius, no text padding); .ow-btn-compact is a flat, reduced-height text button. Both ink adaptive var(--fg) — LIGHT over the dark wallpaper, DARK inside a light-glass card — and both SNAP to 44×44 on a coarse pointer (WCAG 2.5.5). Sub-44px on desktop is the point.

Password reveal — .ow-pw-field / .ow-pw-reveal (#1638)

A treatment on an .ow-field/.ow-input, not a standalone control: a relative .ow-pw-field wrapper reserves trailing room and hosts an in-field .ow-pw-reveal eye button that flips the input password↔text. The eye-open / eye-closed glyph pair swaps by the [aria-pressed] CSS state; the toggle is keyboard-reachable (no tabindex="-1") and carries aria-pressed with the aria-label swapped Show↔Hide in lockstep. Ink is a neutral control token, never an accent. Owner ruling (2026-07-15): this lane standardizes the existing login toggle only — in-app secret fields keep their bare type=password; the kit primitive + OrwellPwReveal.attach exist so a field can adopt it later.

Swatch grid — .ow-swatch-grid / .ow-swatch (#1638)

The Theme window's selectable preset/custom tiles: a role="listbox" grid of role="option" .ow-swatch tiles. A tile displays colors, so it is never a glass material on any tier.

Keycap — .ow-kbd / .ow-kbd-group (#1638)

The Settings → Shortcuts key-chips: a passive <kbd class="ow-kbd"> glyph rendering one key of a combo. Emphasis is the RAISED CHIP SHAPE (a physical key), never an accent hue on the glyph — the exact color: var(--accent) contract the legacy .shortcut-key kbd violated. Portrait tile — .ow-portrait / .ow-portrait-tile (#1638)

Resize handle — .ow-resize-handle (#1638)

The thin, edge-hugging grab affordance that drives a container's width (or height) by drag and keyboard — the gadget-rail width grip. It is a grip, not a value control, so it is not .ow-slider (a track + thumb painting a value): a transparent hit strip that paints a 2px neutral glass-rim bar on hover / active-drag (never an accent or red — the colorless-glass contract) and the one sanctioned system-blue on keyboard focus (the bar is the focus signal). The kit supplies the full-height extent (inset-block:0) + strip width; the edge anchor is consumer-owned via [data-edge]. The consumer keeps all drag / keyboard / clamp / persist logic (role="slider" + aria-value* + Arrow-key nudges).

Progress & chip — .ow-progress / .on-chip (#1638)

Two display-only overlays (both pointer-events:none in the wild) migrated off bespoke fills onto kit tokens (G8, season-progress). The .ow-progress primitive is a reusable progressbar (token track + .ow-progress-fill; the fill keeps the accent chain — a progress FILL is a legitimate accent use); .ow-progress--edge is the fixed bottom-edge season bar. The .on-chip is a static notice-family pill — the drift-fix drops the old --mono face for --ow-ui-font, the accent-tinted ink for legible --fg, and the accent border for --ow-glass-rim-border. Neither is interactive — no hover / focus / tab-stop; the ARIA role="progressbar" lives on the consumer element.

Menus & popovers (#1638) — OrwellMenuKit.attach / OrwellPopoverKit.open

The anchored-surface kit: one flip/shift positioning engine, one escMenuStack dismiss seat (Escape drains menus first), a roving-tabindex role="menu" contract, and the .ow-menu / .ow-popover glass family. OrwellMenu renders a declarative item model (icons, danger, disabled, checkbox, shortcut, separator, section header, a nested submenu, a two-line description); OrwellPopover serves rich custom content. Menus stay anchored on every viewport (owner ruling 2026-07-15 — no sheet reflow). Click a trigger, then arrow-key / type-ahead through it and press Escape.
