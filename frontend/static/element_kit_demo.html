Gadgets — OrwellGadgetKit.create(…)

The rail gadget kit (.og-card with .og-head + .og-body, action buttons, collapse chevron, system-blue :focus-visible header ring). Every real player-tier gadget KIND, instantiated live: House Status ("The House" HUD) · Your Deals · Where You Are · Nightfall (time/presence) · Cast · Alliances.

Decision — OrwellDecision (.odec-*)

The decision card the kit renders above the composer: prompt + selectable option buttons + a confirm action + an instruction note. Static composition of the kit's .odec root class + .odec-* internals with the REAL button classes the live card composes (ow-btn ow-btn-prominent); the structural CSS is injected by orwellDecision.js via window.OrwellDecisionStyles.ensureStyles(). Low-stakes example: a comp-intent (the live eviction vote is a HIGH-STAKES kind and wears the risk skin — see the second card).
