Windows — OrwellWindowKit.create(…)

Types/states: standard (HUD), modal:true (centered, scrim'd dialog), dockable (docked into the control room); minimizable / closable / resizable / draggable; persisted layout + cross-device sync.

Gadgets — OrwellGadgetKit.create(…)

The rail gadget kit (.og-card with .og-head + .og-body, action buttons, collapse chevron, system-blue :focus-visible header ring). Every real player-tier gadget KIND, instantiated live: House Status ("The House" HUD) · Your Deals · Where You Are · Nightfall (time/presence) · Cast · Alliances.

Decision — OrwellDecision (.odec-*)

The decision card the kit renders above the composer: prompt + selectable option buttons + a confirm action + an instruction note. (Static composition of the kit's .odec-* classes — the live card is driven by game state.)
