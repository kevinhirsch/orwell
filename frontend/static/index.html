Admin

Default Chat Model

The model used when creating a new chat session.
How hard the narrator thinks before it replies and calls engine tools. Low suits GLM-4.7 (its interleaved thinking is what decides tool calls); off is cheapest but can skip a needed call. Same setting as Token Economy → Narration.

Utility Model (Recommended: Local Endpoint)

Runs background tasks (compaction, cleanup, auto-naming, retrieving memories from files) on a small/local model instead of your chat model. Leave blank to use the chat model.

Runtime overseer

Supervises the engine↔LLM loop. Pacing catches stalls and missed engine calls; Faithfulness checks the narration against engine truth. Off = the deterministic floor stands · Shadow = diagnose & log only · Active = correct live (live-LLM only). The ORWELL_OVERSEER_MODE / ORWELL_FAITHFULNESS_MODE env vars are the headless fallback when these are left unset.

Faithfulness judge model

The model that judges narration faithfulness (used only when the gate above is on). Leave blank to use the Utility model (then the chat model).

Vision

Analyze images with a vision-capable model.

Research Model

Model used for Deep Research. Falls back to the default chat model if not set.

Agent

Controls for the agent tool loop.

🌙In-Game Time & Sleep

A live in-game clock (morning to late night): the house thins as houseguests turn in for the night, staying up late dulls the next competition, and a "Nightfall" gadget shows who's still up. Applies to the live game immediately - no restart.

📊Token Economy

Control model token spend on live-game turns (ADR 0010). Reasoning effort per call class is the dominant cost lever; the OpenRouter provider object steers routing & caching; tiering trades cost to keep a long game's memory. Applies immediately - no restart. Watch spend at /api/admin/token-economy.

Public deployment

Connect this deployment to the internet over a Cloudflare tunnel — no SSH, no hand-editing the environment. Account-side steps (domain, tunnel, Access/WAF) stay in Cloudflare's dashboard; Orwell never holds your Cloudflare account credentials.

Step 1 — set up your Cloudflare account & domain
Done in the Cloudflare dashboard — Orwell only collects the resulting connector token. Sign up, add your domain (change nameservers at your registrar), then create a remotely-managed tunnel and map its public hostname to http://127.0.0.1:8080. Add Cloudflare Access/WAF for who-can-reach-it controls.
Cloudflare sign-up Zero Trust dashboard (tunnels) Tunnel docs
Step 2 — paste your connector token & domain(s)
The connector token is write-only — it is consumed on the box and never shown back here.

Local HTTPS

Serve the game over HTTPS on your LAN — orwell.lan, orwell.local, and the box's IP — with no browser warning. Works whether or not the public domain above is set. The local names use a built-in certificate authority; trust its root once per device and the warning is gone.
Loading…
Local names to cover
The box's LAN IP is added automatically. Make sure these names resolve on your network (orwell.local works out of the box via mDNS; orwell.lan needs a router/DNS entry).
Optional — also serve a public domain with a publicly-trusted cert
Zero per-device install. Needs the domain plus a DNS provider API token (a DNS-01 challenge), resolved to this box on your LAN.
The DNS token is write-only — it is consumed on the box and never shown back here.

Danger Zone

Irreversible. Each wipe targets one category — pick exactly what you want gone.
Wipe all chats
Every session, message, and chat history. Documents/notes/etc. stay.
Wipe all memory
Clears `memory.json`, the Memory table, and the vector store. Skills not affected.
Wipe all skills
Drops `data/skills/` (all SKILL.md files). Memory not affected.
Wipe all notes
Every note, todo, and checklist.
Wipe all tasks
Every scheduled task and its run history (Tasks tool).
Wipe all documents
Every document and version. Drafts, exports, library — all gone.
Wipe all gallery
Every image record and the upload directory on disk.
Wipe all calendar
Every event and every calendar (incl. CalDAV-synced ones; resync to restore).
