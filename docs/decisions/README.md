the **context**, the **decision**, and the **rationale**, so the "why" survives. Records are
numbered and append-only; a later record may supersede an earlier one (note it in both).

| 0012 | [Two-window lockstep "Messenger mirror" for live game conversations](./0012-two-window-lockstep-mirror.md) | Proposed (2026-06-21); the **live-stream** sibling of 0008 (which reconciles the settled *log*) and 0011 (the concurrent *loop*). Two windows on one game type **divergent** responses during live generation, then snap together late, because the live token stream is **not** a shared resource — each window runs its own open-set generation (0005). Fix (FE-side, the **Messenger mirror**): the turn's narration becomes **one** authoritative server-side run **fanned out token-by-token** to every window on the canonical session (replay-then-live-tail via the existing `agent_runs._Run` primitive, incl. a mid-stream join), + revive the dead `message-added` completion leg. **Not** a turn-lock (0064 stands); closed-set serialization stays the engine's (0065). Build plan: `docs/audits/2026-06-21-mirror-C-fix-design.md`; binding gate = two-window byte-identical token-timeline harness + 50× concurrent smoke + mandatory live-LLM run before merge |
| 0014 | [Local & tunable HTTPS for the player tier (trusted on the LAN, with or without a domain)](./0014-local-and-tunable-https.md) | **Accepted — BUILT** (2026-06-22, feature 0074). A Caddy TLS terminator in front of the FE, driven by tunable `ORWELL_TLS_*` vars from the control panel + the Admin card. Layered trust: an offline internal-CA floor (root downloadable → no warning after one install) + an optional publicly-trusted DNS-01 upgrade (zero per-device install). Independent of public exposure (0007); engine never named. Gates `frontend/tests/test_{tls_routes,local_tls_guard,local_ca_download}.py` + `tests/unit/tlsArtifacts.test.ts` |
| 0013 | [Cast photos require a model-authored identity (no authoring → no photo)](./0013-cast-photos-require-authored-identities.md) | **Accepted — BUILT** (2026-06-21). Owner ruling surfaced in the season→new-season prewarm audit (`UX-AUDIT-LOG.md` R6): a face must be generated **only** from a model-authored identity — a seeded/un-authored likeness fed before its identity is written contradicts the rich authored text later. FE-side in the portrait warm (`frontend/src/orwell_prewarm.py`): a face shoots **iff** its houseguest's per-NPC authoring gate fired; the whole-cast `_on_done` no longer force-opens un-fired gates and a pure timeout no longer shoots; the **backfill** fills a late-authored NPC. Builds on 0065/0058/0051; bounded by the Vault Wall + non-degradation. Gates `frontend/tests/test_adr0013_photo_requires_authoring.py` + `test_0065_cast_prewarm.py` |
